Chat UIs are easy to ship. Trust is not.

When an agent answers “what is revenue?”, the happy path should **compile** from governed metric definitions — same joins, same filters, every time. When it asks “what breaks if I change this model?”, the path should **traverse** a verified relationship graph.

Semgraf is that dual-plane runtime: metrics compile, relationships verify, and every answer carries a trace.

### What we are not building first

- Another catalog UI
- Another agent that invents SQL
- A homepage that is only a chatbot

Ask is one surface. The product is the runtime under your agents.
